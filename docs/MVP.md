# 🧩 MVP – Minimum Viable Product

## Ziel

Ein lauffähiger **monophoner** Synthesizer mit ADSR, der als Standalone- und VST3/LV2/CLAP-Plugin unter Linux funktioniert.

---

## Inhalt des MVP

| Komponente                     | Status     |
| ------------------------------ | ---------- |
| 1 Oszillator (Saw/Sine)        | ✔          |
| 1 ADSR (Amplitude)             | ✔          |
| Grund-Filter (Tiefpass)        | ✔          |
| MIDI Note-On/Off               | ✔          |
| GUI mit Reglern (ADSR, Cutoff) | ✔          |
| VST3/LV2/CLAP-Build            | ✔          |
| Polyphonie                     | ✖ (später) |
| Presets                        | ✖ (später) |
